# 抖音评论关键词名单挖掘（B 版脚本）

给抖音视频链接 + 关键词，脚本自动打开视频、滚动加载评论区、把命中关键词的
评论用户（昵称 + 评论 + 主页链接）抓出来，导出成 CSV 名单。

**定位：只做「导名单 / 看反馈」，不做私信 / 批量触达。**
批量私信陌生人是抖音重点打击的违规引流，且涉及个人信息合规，别拿它群发。

---

## 一次性准备

```bash
cd douyin-comment-miner
python3 -m pip install -r requirements.txt
```

脚本驱动你电脑里已装的 **Google Chrome**，不用再下载浏览器内核。

> 若官方源下载超时（国内常见），改用阿里云镜像：
> `python3 -m pip install -i https://mirrors.aliyun.com/pypi/simple/ playwright`

首次使用先登录一次，登录态会存到 `~/.douyin_miner_profile`，以后免扫码：

```bash
python3 douyin_miner.py --login
```

弹出的窗口里扫码登录抖音 → 回到终端按回车，即保存完成。

---

## 日常使用

单个链接 + 单个关键词：

```bash
python3 douyin_miner.py "https://v.douyin.com/3NzZzk1fcBo/" -k 郝美丽
```

整段分享文案（带一堆乱码前缀）直接粘进来也行，脚本会自动抠出链接：

```bash
python3 douyin_miner.py "3.30 :2pm ... https://v.douyin.com/xxxx/ 打开Dou音搜索" -k 郝美丽
```

多个关键词（命中任意一个即入选）+ 指定输出文件名：

```bash
python3 douyin_miner.py "链接1" "链接2" -k 报价 -k 多少钱 -o 名单.csv
```

连子回复一起抓（更全，但更慢、更容易触发风控，默认关闭）：

```bash
python3 douyin_miner.py "链接" -k 郝美丽 --with-replies
```

## 参数说明

| 参数 | 作用 | 默认 |
|---|---|---|
| `links`（位置参数） | 一个或多个视频链接 / 分享文案 | — |
| `-k, --keyword` | 关键词，可重复传多个，命中任意一个即入选 | — |
| `-o, --out` | 输出 CSV 路径 | `抖音评论名单.csv` |
| `--login` | 只登录并保存登录态后退出 | 关 |
| `--with-replies` | 连同子回复一起抓 | 关 |
| `--max-comments` | 单个视频最多滚动收集多少条主评论 | 3000 |
| `--headless` | 无头运行（需要已完成 `--login`；调试建议别开） | 关 |

## 输出

跑完会同时得到两个文件（同目录）：

- `名单.csv`：UTF-8 带 BOM，Excel/WPS 双击打开不乱码。
- `名单.xlsx`：链接是**可点击超链接**，点「私信 →」直接打开该用户主页。

列：`视频ID, 昵称, 评论内容, 主页链接, 私信入口(主页点私信)`

关于「私信入口」：抖音网页没有直达“和某人会话”的公开链接（陌生人会话未建立，无 URL），
所以这一列给的是**对方个人主页**——在页面上点一下「私信」即可给对方发消息。
注意：若对方设置了“仅朋友可发私信”，会发不出去，这属正常。

同一用户多次命中会各占一行；按人去重，用「主页链接」列去重即可。
昵称偶尔为空是抖音端用户改过名，主页链接照样能点进去认人。

## 常见情况

- **弹到登录页 / 抓不到评论**：先跑一次 `--login`。登录态过期后重登一次即可。
- **越滚越慢或刷不出更多**：视频评论量很大时抖音会限流，属正常。歇几分钟再跑，别短时间连续开很多视频。
- **评论数比页面显示少**：抖音默认只展开主评论，子回复里提到关键词的人需要 `--with-replies` 才会被抓到。
- **想长期定时 / 大规模**：本地脚本适合中小批量；上万条、要稳定全量的场景更适合第三方数据服务。
