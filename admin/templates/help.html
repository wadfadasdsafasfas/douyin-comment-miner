使用说明
听潮控制台管理员手册

核心流程

  1. 创建用户（分配初始密码 + 有效天数）
  2. 把账号密码发给客户，客户在客户端登录
  3. 客户到期前来后台续期
  4. 客户端自动检测 /api/latest，有新版就提示升级

用户管理

  • 创建：「创建用户」按钮 → 填用户名 / 密码 / 到期日
  • 改到期：📅 按钮，可选快捷（+30 / +90 / +1 年 / +3 年）或自定义
  • 改密码：🔑 按钮，重置后客户端需重新登录
  • 启停：⏻ 按钮，停用后该用户无法登录；可随时恢复
  • 删除：🗑 按钮，不可撤销，所有 token 同步清除
  • 管理员账号（admin）不可被改期 / 改密 / 删除

版本与升级

  • 最新版本：客户端启动时检测到这个就提示升级
  • 最低允许版本：低于这个版本的客户端会被服务端拒绝登录（强制升级）
  • 强制升级开关：勾选后最低版本限制生效
  • 下载链接：通常是 GitHub Actions 出包后填入
  • 更新说明：会显示在客户端升级弹窗里

常见问题

  • 客户说「升级失败」 → 看 /opt/app/downloads/ 上的 zip 是否完整（sha256sum 对比 GitHub release）
  • 客户说「登录不上」 → 看是否到期、是否停用、是否被另一设备顶（单设备登录限制）
  • 客户端一直提示升级 → 检查 latest_version 是否填错（比如多了空格 / v 前缀）
  • 改了配置不生效 → 看后端服务进程是否还在；本后台只是入口，所有状态存在后端 SQLite
